# Student Task Tracking

This context describes the language used to manage an individual Student's academic work.

## Language

**Student**:
An individual university or college student who manages personal academic work across multiple Courses.
_Avoid_: User, learner, pupil

**Academic Task**:
A piece of personal academic work that a Student needs to track and complete.
_Avoid_: Todo, item, assignment

**Due Date**:
The calendar date by which an Academic Task should be completed.
_Avoid_: Deadline, target date

**Task Title**:
A short description that identifies the academic work represented by an Academic Task.
_Avoid_: Name, description

**Course**:
The university or college course to which an Academic Task belongs.
_Avoid_: Subject, class, category

**Pending**:
The status of an Academic Task that the Student still needs to complete.
_Avoid_: Active, incomplete, open

**Completed**:
The status of an Academic Task that the Student has finished.
_Avoid_: Done, closed

**Overdue**:
A condition of a Pending Academic Task whose Due Date has passed.
_Avoid_: Status, late status
